# AIRCOURT — демо-версия сайта

Сайт учебного магазина баскетбольной экипировки AIRCOURT, выложенный на GitHub Pages.

Полная версия проекта — программа на C# (Windows Forms + SQLite) со встроенным сервером сайта.
Здесь лежит только сайт: на GitHub Pages нет сервера, поэтому:

- товары, категории и подборки взяты из базы и сохранены в папке `data/` (JSON);
- вход, корзина и заказы работают прямо в браузере (`localStorage`) — у каждого посетителя свои;
  в демо подходят любые email и пароль, промокод для проверки — `AIRCOURT10`;
- админ-панели в демо нет.

Как это устроено: все запросы сайта к серверу проходят через одну функцию `api()` из `common.js`.
Файл `demo-api.js` подменяет её и отвечает сам по тем же правилам, что и сервер программы
(доставка 490 ₽, бесплатно от 10 000 ₽, промокод на 10 %, проверка размера и остатка).
